GNXAS EXAFS Data Analysis Software Suite

The GNXAS package is an advanced software for EXAFS data analysis based on multiple-scattering (MS) calculations and a rigorous fitting procedure of the raw experimental data.

⚛️

Main Characteristics of GNXAS

▼ Read Full Technical Details
✓
Atomic phase shifts calculations in the muffin-tin approximation based on atom self-consistent relativistic calculations. Account for surrounding neighbors is taken.
✓
Inclusion of inelastic losses through complex energy-dependent Hedin-Lundqvist potentials.
✓
Calculation of multiple-scattering (MS) signals associated with two, three, and four atom configurations using advanced curved-wave algorithms.
✓
Full modularity that makes it easy to interface parts of the GNXAS software with other available scientific tools.
⚡ Advanced Fitting Procedure Capabilities:
Fit simultaneously any number of spectra containing any number of edges.
Use directly the raw data without requiring any mandatory pre-analysis.
Account for complex background multi-electron excitation features.
Use model peaks for pair ($g_2$), triplet ($g_3$), and quadruplet ($g_4$) distribution functions (including non-Gaussian & extremal models).
Treat liquid phase or disordered systems and extract reliable short-range $g(r)$ functions.
Perform a rigorous statistical error analysis and plot two-dimensional correlation maps.
Flexible open scientific tool where the user has full access to every stage of calculation — GNXAS is not a black box.

"Its flexibility and advanced characteristics are essential to perform a modern EXAFS data-analysis and to extract accurately all the valuable information contained in your data."

Institutional Support: GNXAS was supported by the Italian Consiglio Nazionale delle Ricerche (CNR) (contract 98.00475.ST76). Later on, INFM supported developments in 1999–2003.

Program Modules

Software Suite Architecture

Modular program architecture structured into specialized computational engines, cluster pre-processors, and post-processing tools.

Computational Workflow

Integrated Pipeline Architecture

The GNXAS workflow executes a streamlined computational path: starting from potential generation (PHAGEN), 3D cluster definition (CRYMOL & GNPEAK), curved-wave MS signal computation (GNXAS), and non-linear data refinement (FITHEO).

Core Backbone Engines

PHAGEN Potential & Phase Shifts

Relativistic muffin-tin atomic potential generator calculating phase shifts $\delta_l(E)$ and complex Hedin-Lundqvist self-energy potentials.

GNXAS MS Signal Calculator

Curved-wave multiple-scattering signal generator for 2-body ($\gamma^{(2)}$), 3-body ($\gamma^{(3)}$), and 4-body ($\gamma^{(4)}$) reference geometries.

FITHEO Non-Linear Least Squares

Advanced structural refinement program executing non-linear least-squares optimization using the CERN MINUIT minimization engine.

Pre-Processors & Cluster Generators

CRYMOL Cluster Generator

Generates 3D atomic coordinates from molecular ($XYZ$) or space-group crystallographic ($CRY$/$SYM$) data input files.

GNPEAK Sub-cluster Filter

Identifies and filters inequivalent 2-body, 3-body, and 4-body local sub-clusters to construct optimized GNXAS input models.

⚙️ Extended & Specialized Program Modules (Visualization, Liquids g(r), Advanced RMC)
▼ View 11 Additional Program Modules

Output & Visualization Utilities

PHAPLO Phase Shift Plotter

Graphical visualization utility for inspecting PHAGEN phase shifts $\delta_l(E)$ and atomic mean free path functions.

READDER Binary Converter

Converts binary GNXAS multiple-scattering signal files into clean, readable ASCII column format for plotting.

CONTOUR Error Mapping

Converts character-based MINUIT output into 2D statistical confidence contour maps for rigorous parameter error analysis.

Disordered Systems & Liquids g(r)

GRFIT Model g(r) Fitter

Fits analytical model radial distribution functions $g(r)$ to liquid and disordered experimental EXAFS data.

GRXAS EXAFS Calculator

Calculates expected EXAFS signals for given partial pair distribution functions $g_{ij}(r)$ derived from MD or MC simulations.

GRREC g(r) Reconstruction

Reconstructs short-range radial distribution functions $g(r)$ directly following non-linear structural optimization.

Extended & Advanced Utilities

RMC-GNXAS (RMCXAS) Reverse Monte Carlo

3D Reverse Monte Carlo structural refinement constrained simultaneously by diffraction, MD/MC, and EXAFS MS signals.

JESF / NEWJESF Synchrotron Pipeline

Automated EXAFS extraction, Fourier transform, and noise evaluation pipeline routinely deployed at ESRF & Elettra beamlines.

DECONV Lifetime Deconvolution

Core-hole lifetime broadening deconvolution program for high-resolution XANES spectrum sharpening.

PEAKFIT & EDXRD High-Pressure Diffraction

Refinement package for energy-dispersive X-ray diffraction (EDXD) peak fitting under extreme high pressure.

XASAM Sample Optimizer

Transmission sample thickness and absorption jump optimizer for designing beamline XAS experiments.

Scientific Legacy

Who Wrote GNXAS

Several scientists have contributed to the development of GNXAS since 1989. It contains the most up to date algorithms for EXAFS data analysis directly coded by the investigators. It was soon realized that the use of these programs could have been appreciated by scientists in various fields willing to perform advanced applications of the EXAFS technique. For this reason the programs were made available to the scientific community.

⚠️ User Warning on Code History & Complexity:
We should warn the users however that as a result of this history GNXAS is not a trivial and "user proof" code. The complexity of some of the algorithms makes the required input very cumbersome and INPUT mistakes can be sometimes hard to identify.

C. R. Natoli

INFN - Laboratori Nazionali di Frascati

The research effort was based on the work of C. R. Natoli, a pioneer of multiple-scattering applications to EXAFS spectroscopy. Natoli is the main author of the PHAGEN program where all the theory for potential calculation is included.

A. Filipponi

Università dell'Aquila

The GNXAS code was mainly written by A. Filipponi, implementing efficient codes for MS calculations with fast matrix products and continued fraction approaches. Co-author of early full 1990 releases.

A. Di Cicco

Università di Camerino

FITHEO has been mainly written by A. Di Cicco. A complete version of GNXAS was already available in 1990. Author of RMC-GNXAS, EDXRD, and leader of UNICAM XAS Group.

Several algorithms and approaches implemented in the package have been jointly developed by the authors. Other programs and algorithms, like RMC-GNXAS, EDXRD (Di Cicco), and DECONV, XASAM (Filipponi) have been developed separately by the authors.
