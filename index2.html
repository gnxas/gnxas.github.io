GNXAS EXAFS & MS Suite

The GNXAS package is an advanced software for EXAFS data analysis based on multiple-scattering (MS) calculations and a rigorous fitting procedure of raw experimental data.

⚛️

Main Characteristics of GNXAS

▼ Technical Details
✓
Atomic phase shifts calculations in muffin-tin approximation based on atom self-consistent relativistic calculations.
✓
Inclusion of inelastic losses through complex Hedin-Lundqvist energy-dependent potentials.
✓
Multiple-scattering signals associated with 2-body ($g_2$), 3-body ($g_3$), and 4-body ($g_4$) atom configurations.
✓
Advanced fitting procedure: fit simultaneously any number of spectra/edges, direct raw data fitting, liquid state $g(r)$ extraction, MINUIT error analysis.

Software Suite Architecture

Computational Pipeline

Integrated Modular Execution

Executes potential generation (PHAGEN), cluster construction (CRYMOL & GNPEAK), curved-wave MS signal calculations (GNXAS), and structural refinement (FITHEO).

PHAGEN

Relativistic muffin-tin atomic potential & Hedin-Lundqvist phase shifts generator.

GNXAS

Curved-wave MS signal calculator for 2-body, 3-body, and 4-body configurations.

FITHEO

Non-linear least squares structural refinement using CERN MINUIT optimization.

Scientific Legacy

Who Wrote GNXAS

Several scientists have contributed to the development of GNXAS since 1989. It contains the most up to date algorithms for EXAFS data analysis directly coded by the investigators.

⚠️ Warning on Code Complexity: GNXAS is not a trivial or "user proof" code. The complexity of some algorithms makes the required input cumbersome and input mistakes hard to identify.

C. R. Natoli

INFN - Frascati

Pioneer of MS applications to EXAFS. Main author of PHAGEN potential engine.

A. Filipponi

Università dell'Aquila

Main author of GNXAS core engine, continued fraction matrix products, DECONV, XASAM.

A. Di Cicco

Università di Camerino

Main author of FITHEO, RMC-GNXAS, EDXRD, and leader of UNICAM XAS Group.
